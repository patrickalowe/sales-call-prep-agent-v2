=== THIS IS THE v2 FOLDER (live web search via Tavily) ===

Same tool as v1, but the "Context" step searches the web for current
news (using Tavily) before writing the brief. You will see:
  Researching company (live web search)...
That line is how you know you are running v2, not v1.

NEEDS TWO KEYS in .env:
  ANTHROPIC_API_KEY=...   (Claude, writes the brief)
  TAVILY_API_KEY=tvly-... (Tavily, does the search - get it at app.tavily.com)


=== FIRST TIME SETUP (do this once) ===

cd ~/Projects/sales-call-prep-v2

python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt


=== EVERY TIME YOU COME BACK ===

cd ~/Projects/sales-call-prep-v2
source venv/bin/activate


=== THEN PICK ONE ===

python3 main.py     # terminal version
python3 app.py      # website version (then open http://localhost:5001)


=== COST (every run prints its own) ===

A normal run does 3 Tavily searches, then Claude writes the brief.
Tavily searches are free-tier (3 credits); you only really pay Claude
tokens, which is a few cents. Each run prints a line like:

  Usage: 5,434 in + 2,072 out tokens -> est. $0.047 (Claude) + 3 Tavily search(es)

So a full searched run is about $0.05 and finishes in ~1 minute.

To skip the web search entirely (no Tavily key needed, training data
only), add --no-search:

  python3 main.py --no-search

To change how many searches run, edit the _SEARCH_QUERIES list near the
top of agent.py (one line = one search).
